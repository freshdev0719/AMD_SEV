# 아침 주식 알리미

매일 아침 정해진 시각에 관심 종목 시세를 알림으로 보내 주고, 웹 화면에서 상승·하락을 색상으로 보여 주는 웹 애플리케이션입니다.

- 기본 관심 종목: **삼성전자(005930)**, **SK하이닉스(000660)**
- 종목명 검색(자동완성) 또는 6자리 종목 코드로 종목 추가, 카드의 ✕ 버튼으로 삭제
- 색상 표시 (국내 증시 관례): **상승 = 빨강 ▲**, **하락 = 파랑 ▼**, 보합 = 회색
  - 전일 대비 등락 + 최근 5거래일 흐름(상승세/하락세)과 미니 차트
- 매일 아침 알림 (기본 평일 08:30 KST, 화면에서 시각·요일 변경 가능)
  - 브라우저 웹 푸시 알림 — 페이지를 닫아 두어도 알림이 옵니다
  - "지금 리포트 보내기" 버튼으로 즉시 테스트
- 화면을 열어 두면 1분마다 시세 자동 갱신, 다크 모드·모바일 지원

## 실행

Node.js 18 이상이 필요합니다.

```bash
npm install
npm start
# http://localhost:3000 접속
```

1. 화면 아래 **아침 알림 설정**에서 알림 시각을 정하고 **설정 저장**을 누릅니다.
2. **이 기기에서 알림 받기**를 눌러 브라우저 알림을 허용합니다.
3. **지금 리포트 보내기**로 알림이 오는지 확인합니다.

> 아침 알림은 서버가 보내므로 서버가 켜져 있어야 합니다. 예정 시각에 서버가 꺼져 있었다면 3시간 이내에 켜질 때 그날 리포트를 한 번 보냅니다.
>
> 웹 푸시는 `localhost` 또는 HTTPS 주소에서만 동작합니다. iPhone(iOS 16.4+)은 Safari에서 "홈 화면에 추가"한 뒤 앱에서 알림을 허용해야 합니다.
>
> 장 시작(09:00) 전 알림은 전일 종가 기준 시세입니다. 당일 시초가를 받으려면 알림 시각을 09:05 이후로 설정하세요.

## 환경 변수

| 이름 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | `3000` | 서버 포트 |
| `DATA_DIR` | `./data` | 관심 종목·설정·푸시 구독 정보 저장 위치 |
| `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY` | 자동 생성 | 웹 푸시 키 (없으면 `data/vapid.json`에 생성) |
| `VAPID_SUBJECT` | `mailto:admin@localhost` | 웹 푸시 연락처 |

## 구조

```
server.js           HTTP 서버, REST API, 아침 리포트 실행
src/quotes.js       시세 조회 (네이버 증권, 실패 시 Yahoo Finance) 및 종목 검색
src/scheduler.js    KST 기준 매일 알림 스케줄
src/store.js        JSON 파일 저장소
src/push.js         웹 푸시 전송
src/report.js       알림 문구 생성
public/             웹 화면, 서비스 워커
test/               node:test 테스트 (npm test)
```

## API

| 메서드 | 경로 | 설명 |
| --- | --- | --- |
| GET | `/api/quotes` | 관심 종목 시세 (`?refresh=1`이면 캐시 무시) |
| GET / POST | `/api/stocks` | 관심 종목 목록 / 추가 (`{ "code": "035720" }`) |
| DELETE | `/api/stocks/:code` | 관심 종목 삭제 |
| GET | `/api/search?q=` | 종목 검색 |
| GET / PUT | `/api/settings` | 알림 설정 (`enabled`, `time`, `weekdaysOnly`) |
| GET | `/api/report` | 마지막 아침 리포트 |
| POST | `/api/report/run` | 리포트 즉시 생성·발송 |

시세 데이터는 비공식 공개 API를 사용하므로 지연되거나 바뀔 수 있습니다. 투자 판단의 책임은 본인에게 있습니다.
